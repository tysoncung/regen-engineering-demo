## Scenario: an order requires an address

Given a customer registered with "ada@example.com"
When the customer places an order
Then the order is rejected

## Scenario: an order ships to the default address

Given a customer registered with "ada@example.com"
And the customer has addresses "1 First St", "2 Second St"
When the customer places an order
Then the order shipping address is "1 First St"

## Scenario: editing an address does not alter a past order

Given a customer registered with "ada@example.com"
And the customer has addresses "1 First St"
And the customer places an order
When the customer edits address "1 First St" to "9 Ninth St"
Then the order shipping address is "1 First St"

## Scenario: deleting an address does not alter a past order

Given a customer registered with "ada@example.com"
And the customer has addresses "1 First St", "2 Second St"
And the customer places an order
When the customer deletes address "1 First St"
Then the order shipping address is "1 First St"
