id: BR-002
type: business-rule
title: Customer can own multiple addresses with exactly one default
status: active
since: 2026-07-30
affects: [customer, orders]
implemented_by: [customer]
verified_by: [CT-002]
---

A customer may register any number of addresses.

Exactly one address is the default shipping address, and this invariant holds
at all times:

- The first address added becomes the default.
- Adding further addresses does not change the default.
- Deleting a non-default address does not change the default.
- Deleting the default promotes the **most recently used** remaining address.
  If no remaining address has ever been used, the **oldest** remaining address
  is promoted.
- Deleting the last address leaves the customer with none, and therefore no
  default.

"Used" means the address was the shipping address of an order.

A customer with no addresses cannot place an order, which is why this rule
affects `orders` as well as `customer`. See
[BR-010](../../../orders/knowledge/rules/BR-010.md).
